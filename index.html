Geovelo / Komoot → Google Maps

Collez une URL d'itinéraire Geovelo ou Komoot : l'outil détecte la source et génère des liens Google Maps (vélo ou marche) qui suivent au mieux le tracé réel.

Convertir une URL

Prérempli automatiquement (vélo pour Geovelo, ou d'après le sport du tour Komoot) ; modifiable.

Résultats

Conçu pour ouvrir sur ordinateur puis « Envoyer vers votre téléphone » ; un navigateur mobile peut limiter l'itinéraire à 3 étapes.

    Aperçu cartographique

      Sources supportées : Geovelo (via le service de routage BRouter, communautaire et gratuit) et Komoot (via son API publique, qui fournit directement le tracé). Fond de carte : © contributeurs OpenStreetMap. Voir le README pour le fonctionnement détaillé et les limites connues.

      Pour un itinéraire Geovelo, cette page envoie les coordonnées de l'itinéraire (départ, étapes, arrivée) au service de routage brouter.de (avec repli automatique en cas d'échec) ; pour un itinéraire Komoot, elle interroge directement l'API publique de komoot.com. Elle charge la bibliothèque cartographique Leaflet depuis le CDN unpkg.com et les tuiles depuis OpenStreetMap, et ouvre des liens vers Google Maps. Aucune donnée n'est stockée ni envoyée à un autre serveur.
